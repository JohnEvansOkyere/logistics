# Research basis for the coding-agent handoff

Checked 2026-09-28. These are **sources of working practices**, not endorsements of our specific stack or a claim that Andrej Karpathy or Andrew Ng published this project's template.

- [Andrej Karpathy, coding workflow notes (Jan 2026)](https://x.com/karpathy/status/2015883857489522876): highlights fallibility, overcomplicated abstractions, human oversight, and verifying agent work with a browser/feedback loop. Applied here: small modules, explicit acceptance criteria, human review of sensitive behavior.
- [Andrej Karpathy, agentic engineering retrospective (Feb 2026)](https://x.com/karpathy/status/2019137879310836075): distinguishes professional agent-assisted engineering with scrutiny from throwaway vibe coding. Applied here: reviewable changes and production checks rather than agent output alone.
- [Andrew Ng, Three Key Loops for Building Great Software (Jun 2026)](https://www.deeplearning.ai/the-batch/three-key-loops-for-building-great-software): agent writes/tests iteratively, developer reviews and steers, users provide external feedback. Applied here: phase-level UAT plus repeatable implementation verification.
- [Andrew Ng, Context for Coding Agents (Mar 2026)](https://www.deeplearning.ai/the-batch/crowdsourced-context-for-coding-agents): up-to-date API documentation prevents incorrect integration assumptions. Applied here: verify vendor documentation and sample payloads before coding OCR, carrier and email/SMS adapters (and WhatsApp later).
- [OpenAI Codex best practices](https://developers.openai.com/codex/learn/best-practices) and [AGENTS.md format](https://agents.md/): concise repo-level instructions, clear goal/context/constraints/done, executable validation and focused reviews. Applied here: short root `AGENTS.md`, linked task-specific docs, phase/checklist gates.
- [Supabase migrations](https://supabase.com/docs/guides/deployment/database-migrations), [securing data](https://supabase.com/docs/guides/database/secure-data), [Storage access control](https://supabase.com/docs/guides/storage/security/access-control), [production checklist](https://supabase.com/docs/guides/deployment/going-into-prod): versioned SQL, keys/privileges, private file access, restores and production checks. Applied here: SQL-only migration source, no frontend secret keys, tested access controls and backup drills.

The many circulating “Karpathy AGENTS.md/CLAUDE.md” repositories are third-party interpretations, **not an official Karpathy project layout**. Source quotes do not replace local tests or client sign-off.
